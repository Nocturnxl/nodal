The first public release of NODAL, a desktop interface for AI models that connects directly to the providers and local servers you choose.

Step-by-step instructions: [installation guide](https://github.com/Nocturnxl/nodal/blob/main/docs/installation.md).

## Read before installing

- **The installers are not code-signed.** Windows shows "Windows protected your PC": choose *More info*, then *Run anyway*. macOS refuses to open the app until you choose *Open Anyway* under *System Settings → Privacy & Security*.
- **Checksums** for every installer are in `SHA256SUMS.txt`. The installation guide shows how to check them.
- **macOS and Linux are experimental.** Those builds pass the full automated test suite and the packaged application starts on the build machines, but nobody has yet used them by hand. On macOS in particular, the first-run permission prompts and voice chat are unverified. If you try one, a [platform test report](https://github.com/Nocturnxl/nodal/issues/new?template=platform_test_report.yml) helps a great deal, whatever the result.
- **No automatic updates.** Download a newer release to update. Your conversations are kept.

## What is in it

- Presets for Venice.ai, OpenRouter, OpenAI, LM Studio and Ollama, plus any OpenAI-compatible endpoint
- Streamed chat with stop, regenerate, continue, edit-and-resend and branches
- System prompts and sampling controls per conversation
- Reasoning shown apart from the answer
- Image input for models with vision
- Venice.ai options: web search, citations, thinking controls, characters (Preview)
- Voice chat with Venice.ai (experimental)
- Full-text search, export and import, passphrase-protected exports
- Optional passphrase encryption of everything on disk, with locking
- API keys encrypted by the operating system and never shown to the interface
- No account, no telemetry, no intermediary server

See the [changelog](https://github.com/Nocturnxl/nodal/blob/main/CHANGELOG.md) for the full list and known limitations.
